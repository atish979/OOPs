# OOP Concepts

This folder was created to demonstrate how to add a folder inside a GitHub repository.

## Topics
- Class
- Object
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Example
```cpp
class Student {
public:
    string name;
    int age;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};
```

This is just an example folder structure for your OOPs repository.
